# Ecom-ui

A modern e-commerce user interface built with Angular, TypeScript, HTML, and CSS.

## Overview

Ecom-ui is a frontend project designed to provide a clean and responsive user interface for e-commerce applications.

## Technology Stack

- **TypeScript** (47.9%) - Type-safe JavaScript for robust development
- **HTML** (30.2%) - Semantic markup for structure
- **CSS** (20.1%) - Styling and responsive design
- **JavaScript** (1.8%) - Dynamic functionality
- **Angular** - Modern web framework

## Setup

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 9.1.4.

### Prerequisites

- Node.js
- Angular CLI

### Assets

Add a folder named `images` inside `/src/assets`

## Development Server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.
